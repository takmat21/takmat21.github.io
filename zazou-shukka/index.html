出荷の一日

ZAZOU 冷凍マウスの、注文から出荷通知までの作業手順です。チェックを入れながら上から順に進めます。チェックは今日の日付ごとに、このブラウザに残ります。

合言葉と手順

言われた言葉で、する手順が決まります。表にない頼みは、自分で手順を作らず、何をするかを確かめてから行います。

言われる言葉する手順
朝の出荷・朝のルーティン朝：注文を落として台帳に書く
追加の出荷・14時になった14時：追加の確認 → 追加があれば朝の手順を「貼れる」所まで。0件なら印刷まで
印刷・伝票印刷（時刻にかかわらず）追加の確認 → 印刷（追加の確認を飛ばさない）
出荷通知（「通知」の言葉があるときだけ）出荷通知
出荷ボード・ボード出荷ボード

朝：注文を落として台帳に書く 朝

  1. 時刻を見て、前回の出荷の作業のあと〜今に届いた注文メールを店ごとに数える
    Amazon「注文確定」／Yahoo!「注文確認」／BASE「商品購入通知」。読むだけ。数えたら先に1行で報告：「新しい注文：Amazon a件／Yahoo! b件／BASE c件」。3店とも0件なら「新しい注文はありません」で終わり。0件の店は画面を開かない。
  2. Amazon：未出荷注文レポートを落とす
    「FBM未出荷注文」タブ →「リクエスト」を1回（4時間に1回だけ）→ 30秒待つ →「リフレッシュ」→ 一番上の行の「ダウンロード」を1回。
  3. BASE：未対応の注文を落とす
    件数を読み、1件以上なら全部にチェック →「選択中○件の注文データをダウンロード」を1回。
  4. Yahoo!：注文データを落とし、承諾メールを送って「処理中」にする
    「ページ内すべて選択」→「注文データダウンロード」→ 番号のリンクを押す（座標では押さない）→「新規注文一覧」に戻って選び直し → ステータス「処理中」＋「同時に注文承諾メールを送信」ON →「更新」→ 確認の窓の「処理内容」を読んでから窓の中の「更新」→ エラー0件を見る。ログイン画面が出たら、ログインしてもらうまで待つ。
  5. 全部の店を見終わってから、1回だけ変換する（--clip 付き）
    ログイン待ちの店があれば、待ってから全部まとめて1回。新しい分が0件なら「新しい分はありません」で終わり。エラーならその文をそのまま伝えて止まる。
  6. 台帳スプシに書く
    値のある一番下の行の次から、「A行番号」の1セルを範囲にして95列をそのまま書く（範囲を A〜CQ と書かない。append は使わない）。
  7. 読み直す
    注文番号が変換結果と同じか、電話番号の先頭の0が残っているかを見る。
  8. 報告する（決まった文で）
    「新しい分は N 件（Amazon a／Yahoo! b／BASE c）。台帳スプシの○〜○行目に書きました。Excel の台帳の最後の行の下で、貼り付けてください。」＋ 注文番号・出荷予定日・お届け予定日の表。「貼れた」と言われるまで何もコピーしない。
  9. 名前の字が「?」になっていないか見るNEW 11/26
    店のCSVの時点で、一部の漢字（例：栁）が「?」になることがある。見つけたら報告で伝え、正しい字を教わったら台帳を直す。Excel と、印刷済みの伝票は手で直してもらう。

14時：追加の確認 14:05すぎ／印刷の前は毎回

  1. まず今の時刻を確かめるNEW 11/26
    時刻を見ずに「14時にもう一度見ます」と答えて、もう14時を過ぎていた。報告や予定を言う前に、必ず時計を見る。
  2. 朝の出荷のあと〜今に届いた注文メールを数える
    読むだけ。返信・ラベル変更はしない。
  3. 全部0件なら店の画面は開かない
    「追加の注文はありません」と言って次へ（14時・印刷なら、印刷の手順へ）。
  4. 1件以上の店だけ、朝の手順を「台帳に書く＋クリップボード」まで聞かずに進める
    ログインが要る店は飛ばして、ほかの店を先に貼れる状態にする。

印刷：B2クラウドで伝票を発行 1日1回、全部まとめて

印刷の前は、必ず「14時：追加の確認」を先に行います。

  1. 今日の CSV を1つにまとめる
    台帳で伝票番号（D列）がもう入っている行は発行済みなので外す。出荷予定日が先の注文も、聞かずに一緒に印刷する。
  2. ヤマトビジネスメンバーズを開き、左の「送り状発行システムB2クラウド」から入る
    B2 のURLを直接開かない。ログイン画面なら、ログインしてもらうまで待つ人の手
  3. 「外部データから発行」→ 先に「取込み開始行」を 1 → あとでファイルを入れる
    順番を守る。入れたあと、開始行が 1 のままか見る。
  4. 「取込み開始」→ 取込み件数が合っていて、修正必要 0件を見る
    修正必要が1件以上なら、エラーデータで検索してエラーの文をそのまま伝えて止まる。「直して」と言われたときだけ直す（例：市区町村が無い → 郵便番号で確かめて B2 と台帳を直す）。
  5. 「印刷内容の確認へ」→ 用紙「A4マルチ用紙」→「合計 N件」を見る →「発行開始」
    沖縄など飛行機の便があると「航空危険物」の窓が出る。冷凍マウスは危険物でないので「伝票発行」を押す。
  6. PDFが出たら、印刷の前に伝票番号を控えるNEW 11/25
    PDFのタブはそのままにして、新しいタブで「発行済データの検索」を開く → 出荷予定日を今日〜30日後にして検索 → 送り状番号と注文番号の組を読む → ハイフンを取って台帳のD列に書く → 読み直す → 検索のタブを閉じる。
    印刷を待つ間にヤマトのログインが切れ、番号を調べるのに入り直しが要ったため。
  7. PDFのタブに戻り、プリンタの絵を1回押す
  8. 「印刷」を押してもらい、「印刷した」まで待つ人の手NEW 11/25
    Canon iP2700 series、A4・縦、カラーは「白黒」。「伝票番号は台帳のD列にもう書きました」と一緒に伝える。
  9. PDFを閉じ、まとめたCSVを消す
    伝票番号は書き済みなので、ヤマトには入り直さない。
  10. 伝票番号（ハイフンなし）を台帳の行の順に1行ずつクリップボードに置く
  11. 報告する（決まった文で）
    「N 件を発行・印刷しました。台帳スプシのD列に伝票番号を入れました。Excel は、○○（一番上の注文番号）の行の伝票番号の空欄で貼り付けてください。」

出荷通知 「通知」と言われたときだけ

出荷通知は取り消せません。対象は、台帳で出荷予定日が今日で、伝票番号が入っている行だけです。

  1. 台帳で対象を選ぶ（出荷予定日＝今日、D列に伝票番号あり）
  2. Amazon：未出荷の一覧で、対象の注文だけチェック →「発送を確認する」
  3. Amazon：出荷日＝今日、発送元＝1つ目、配送業者＝YAMATO TRANSPORT、配送方法＝宅急便、各注文に伝票番号
    注文番号と伝票番号の組を見直してから「出荷通知を送信」を1回。
  4. Amazon：いつもと違う画面のときNEW 11/25・11/26
    • 注文が全部「予約配送」のときは配送方法の欄が無く、「予約配送」と出る。それでよい。
    • お急ぎ便（NextDay）の注文があると「入力した配送方法が正しくないようです」と聞かれる。実際にヤマトの宅急便で出しているので「はい、この配送サービス名で続行」。
  5. Amazon：未出荷の一覧に、対象の注文が残っていないことを見る
    今日が出荷予定日の注文が残っていたら、同じ届け先の注文が台帳にあるか見る（同梱）。あれば同じ伝票番号で出荷通知を送る。新しい伝票は出さない。
  6. Yahoo!：「完了」まで止まらずに進めるNEW 11/26
    出荷待ち→出荷処理中→出荷日・着荷日・伝票番号→出荷済み ✉→注文完了待ち→完了
    • お客様へのメールは「出荷済み」にするときの出荷通知メールの1回だけ（画面の上と下に同じチェックがあれば両方ON）。
    • ほかの段では、メールのチェックを全部外す。確認の窓の「処理内容」にメール送信が無いことを見てから、窓の中の「更新」。
    • 入力情報（出荷日・着荷日・ヤマト運輸・伝票番号）は「入力情報を更新」で先に保存し、エラー0件を見る。
    • クレジットカード決済は「完了」にしないと売上が確定しない。
  7. BASE：注文を開き、商品にチェック →「かんたん発送を使わず発送済みにする」
    配送業者＝ヤマト運輸、伝票番号、メッセージはテンプレート「ZAZOOマウス 出荷通知」。出荷日・着荷予定日を書き足し、文の最後で1文字打って消す。読み直してから「発送済みにする」を1回 →「対応済」を見る。
  8. 通知済みの控えに、注文番号と日付を足す
  9. 報告する
    「出荷通知を N 件送りました（Amazon a／Yahoo! b／BASE c）」

着荷日の決め方：届け日の指定があればその日。なければ出荷日＋配達日数（滋賀から1日。北海道・沖縄・青森・秋田・岩手は2日）。

出荷ボード

声をかける回数を減らすための画面です。人の手が要るのは、ログインと印刷だけにします。

ボタンすること
はじめる件数をメールで見る → 1件以上の店だけ朝の手順 → 追加の確認 → 印刷画面まで
印刷した（通知まで）印刷の後かたづけ → 出荷通知（今日が出荷日の分だけ）
印刷した（通知はあとで）印刷の後かたづけまで
出荷通知を送る出荷通知
見直す台帳と控えを読み直して、ボードを出し直すだけ

Excel 用のコピーは最後に1回だけ。名前・住所・電話はボードに入れません。

共通のきまり

  • 上から順に、書いてあるとおりに行う。書いていないことはしない。迷ったら止めて聞く。
  • 1つの手順が終わるたびに、決まった文で報告してから次へ。報告には毎回、台帳スプシのリンクを独立した1行で付ける。
  • パスワードは入れない。ログインは本人がする。
  • お金の操作・送信・削除など取り消せないことは、本人の言葉があるときだけ。
  • 0件の店・0件の作業は飛ばす（開くだけで、押さない）。
  • 画面の確認は文字で読む。スクリーンショットは、文字で読めないときだけ。
  • ボタン・リンクは要素を探して押す（座標で押さない）。ボタンは1回だけ押す。うまくいかないときは押し直さず、画面を読んで伝える。
  • 画面が変わるたびに、確認の小窓で止まらないための JavaScript を最初に入れる。 
    window.__a=[];window.alert=m=>window.__a.push(String(m));window.confirm=m=>{window.__a.push(String(m));return true;};
  • 自動の作業は、終わったとき・止まったときに必ず知らせる。本人がすることを先に書く。
  • お客様の名前・住所・電話は報告に書かない。
  • 時刻にかかわる返事の前に、今の時刻を確かめる。NEW 11/26
