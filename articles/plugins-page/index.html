Claudeの「Plugins」ページ統合：11月30日までに確かめること

スキル・コネクタ・プラグインの設定が、1つのページにまとまる

文：松村貴士（ZAZOU株式会社）｜下書き：統括AI　｜　2026年11月10日

ひとことで言うと

Claudeでは、これまで「スキル」「コネクタ」「プラグイン」の設定が別々のタブに分かれていました。これが「Plugins」という1つのページにまとまります。サイドバーの「Customize」は「Plugins」という名前に変わります。すでに入れてあるスキル・コネクタ・プラグインは、そのまま残ります。

気をつけるのは1点だけです。チーム（Team）・企業（Enterprise）向けプランで、組織の「スキル」をオフにしている場合、2026年11月30日から、デスクトップ版のClaudeでもプラグインが使えなくなります。

いつ、だれに

プラン時期やること
Free・Pro・Max・Ultra10月29日から順に切り替え。11月9日に全体へなし
Team同上。「スキルがオフならプラグインも止まる」決まりは11月30日から組織の「スキル」がオンかを確かめる
Enterprise11月30日から標準でオン同上

公式の説明では「ほとんどの利用者は何もする必要がない」とされています。

何が止まるのか

  • 組織で「スキル」がオフになっていると、11月30日からClaudeのデスクトップ版でプラグインがブロックされます。
  • 公式の説明では、Cowork と Code タブでもプラグインが止まると書かれています。
  • Web版と Claude Code は、いまもすでに同じ動き（スキルがオフならプラグインも使えない）だと説明されています。

つまり、「スキルはオフ、でもデスクトップ版のプラグインは使えていた」という組織だけが、11月30日に急に使えなくなります。

確かめる場所と手順（組織のオーナーが行う）

  1. Claudeの「Organization settings（組織の設定）」→「Library」→「Policy」を開く。
  2. 「Cloud code execution and file creation（コードの実行とファイル作成）」がオフなら、オンにする。プラグインはこれを必要とします。
  3. 「Skills」をオンにする。この項目は、11月30日に「Plugins」という名前に変わります。

逆に、組織としてプラグインを使わせたくない場合は、「Skills」をオフのままにしておけば止まります。

新しい「Plugins」ページでできること

  • 自分が入れているものが、先頭にまとめて表示される（「Your plugins」→「Show all」で全部を確認）。
  • スキルだけ、コネクタだけ、のように絞り込める。
  • 公開されているプラグインに「Verified（確認済み）」「Community（利用者の作成）」の表示が付く。
  • スキルは、チャットの「+」または「/」から呼び出せる。
  • 管理者の画面は、「Plugins」というまとまりの中に、プラグイン・コネクタ・ポリシー・マーケットプレイス・申請のページが並ぶ。

小さな会社で気をつけること

  • だれが設定を見るかを決めておく。AIに任せる仕事が増えるほど、「スキルやプラグインがある日止まった」ときの影響が大きくなります。設定画面を見る人と、見る時期を決めておくと安心です。
  • 入れる前に、作り手を確かめる。「Verified」と「Community」の表示は、その目安になります。プラグインはAIにできることを増やす道具なので、出どころの分からないものは入れないのが基本です。
  • 医療の情報を扱う場合。公式の説明では、HIPAA向けの設定で使っている組織でも、コネクタ・プラグイン・スキルは契約（BAA）の対象外とされています。保護すべき健康情報は入れないよう案内されています。

ZAZOUではどうするか

ZAZOUは、仕事ごとの手順をスキルにまとめ、コネクタでGmailや表計算につないで毎日動かしています。止まると朝の定時作業から影響が出るため、11月30日までに、代表が自分のアカウントの「Plugins」ページと組織の設定を開いて確かめます。確かめた結果は、この記事に書き足します。
