数値から、図面をつくる。SyncDraft

SyncDraft（シンクドラフト）は、部品や部屋の寸法を数値の表で持ち、その表から2D図面（DXF・PDF）と3D（STEP・STL）を出すCADです。
機械の図面は SyncDraft-M、建築・土木・設備の図面は SyncDraft-K で描きます。

Features

SyncDraftでできること

SyncDraft は現在、ZAZOU の図面の仕事で使っています（販売・配布はしていません）。

  1. 数値表から図面を作り直せる寸法を数値の表で持っています。表の値を変えると、図面を作り直せます。変えた値は、図面の数値表に「＊」で分かります。
  2. 2D図面と3Dを出せる2D図面は DXF（mm単位、レイヤー・ブロック・寸法つき）と PDF、3D は STEP・STL で出せます。Jw_cad で開ける DXF も出せます。
  3. 線の太さつきのA3図面外形線・かくれ線・中心線・寸法線などを、分野の規格の太さで描いた A3 の図面にします。
  4. 出す前に自分で点検するどこも指していない寸法、数字や文字の重なり、文字を横切る線があると、図面を保存する前に止まります。
  5. 数量拾いの色分け図面拾った記号ごとに品目の色の印と番号を付け、凡例と個数を入れた色分け図面を作れます。数量表と1つずつ照らし合わせられます。
  6. 直感的な操作図面が画面の8割以上を使い、ボタンは作業ごとのタブに収納しています。
    使いたい道具は名前でさがせます。
    ブラウザで動くので、どこでも開けます。

SyncDraft-M

機械の図面をつくる「SyncDraft-M」

SyncDraft-M は、機械の部品図・組立図・板金の展開図をつくるCADです。
機械製図の決まりで描きます。
下の図面は SyncDraft-M で作った提案例です（図を押すとPDFが開きます）。

  1. 寸法を変えるだけで、図面を作り直せる寸法を数値の表で持つので、版ちがいの図面も表の値を直すだけでできます。
    変えた値には「＊」が付きます。
  2. 2D図面と3Dが食いちがわない同じ数値から図面と3D（STEP・STL）を出すので、図面と3Dのずれが起きません。
  3. JIS の描き方が最初から入っている線の太さ・矢印・文字の高さ・第三角法を、毎回決めなくても規格どおりに描きます。
  4. 出す前に、自分で点検するどこも指していない寸法や、数字の重なりがあると保存できません。

SyncDraft-K

建築・土木・設備の図面をつくる「SyncDraft-K」

SyncDraft-K は、建物と土木の図面、設備の図面をつくるCADです。
建築・土木・設備、それぞれの基準で描きます。
下の図面は SyncDraft-K で作った提案例です。
寸法・数量は提案例の値で、実在の建物・会社とは関係ありません。

  1. 図面と数量が食いちがわない拾った記号に番号と色の印を付け、数量表と1つずつ照らします。
    合わなければ図面を出しません。
  2. 建築・土木・設備の基準がそれぞれ入っている建築は黒丸の寸法とカンマ、土木は「1:200」とカンマなし、設備は標準図の記号で描き分けます。
  3. 1つの数値から、平面・展開・拾い図まで同じ数値から図面と数量の表を出すので、どれかを直せば全部がそろいます。
  4. Jw_cad・AutoCAD で開ける形で渡す相手の CAD に合わせた文字コードと書体の DXF を出します。
