用語集

AIを仕事に使うときによく出てくるカタカナ言葉を、やさしく説明します。

スキル・プラグイン・ナレッジが実際にどう組み合わさっているかは、自社の仕組みで図にしています。

AIの基本

生成AI

文章や画像などを、新しく作り出すAI

聞いたことに合わせて、文章・画像・表などを作ります。ChatGPTやClaudeがその例です。

たとえば　お客様への返信メールの下書きを作ってもらいます。

プロンプト

AIに出す指示や質問の文章

指示が具体的だと、答えも思いどおりになりやすくなります。目的、相手、書き方を添えるのがコツです。

たとえば　「50代の常連のお客様向けに、納期が遅れるおわびを3行で」と頼みます。

モデル

AIの頭脳にあたる部分

会社や世代によって、得意なことや速さ、料金が違います。仕事に合わせて使い分けます。

たとえば　長い文章を読む仕事は得意なモデル、短い仕分けは軽いモデルに任せます。

トークン

AIが文章を数えるときの単位

AIは文章を細かく区切って読み書きします。この区切りの数が、使える長さや料金の目安になります。

たとえば　長いPDFを読ませるときは、トークンが多くなるので料金も増えます。

ハルシネーション

AIが、もっともらしい間違いを答えること

AIは知らないことでも、自然な文章で答えることがあります。大事な内容は、元の資料で確かめます。

たとえば　AIが書いた取引先の設立年を、会社案内で見比べて確認します。

AIエージェントのしくみ

AIエージェント

手順を考え、道具を使って、仕事を進めるAI

質問に答えるだけでなく、メールを読む、表に書く、といった作業まで進めます。決めた範囲の中で動きます。

たとえば　毎朝メールを読み、返事が要るものを一覧にしてもらいます。

スキル（手順書）

AIに渡す、仕事のやり方と確かめる順番を書いた手順書

毎回説明しなくても、同じ手順で仕事ができます。直したことを書き足すと、次から反映されます。

たとえば　「請求書の確認は、金額、宛名、日付の順に見る」と書いておきます。

プラグイン（道具とのつなぎ）

AIにメール・表・管理画面などの道具を使わせる追加の仕組み

AIは、つないだ道具の中だけで仕事ができます。仕事が変われば、必要なプラグインも変わります。

たとえば　営業の下調べ用のプラグインを入れて、商談前の調べものを任せます。

ナレッジ（事実の表・決めたこと・過去の直し）

AIが仕事の前に読む、その会社の情報のまとまり

会社の事実、決めたこと、過去に直したことを入れておきます。使うほど増えて、仕事が正確になります。

たとえば　商品ごとの単価表を入れておき、見積の下書きで使ってもらいます。

コネクタ／MCP

AIと外の道具や情報をつなぐ共通の接続方法

MCPは、つなぐときの共通ルールです。ルールがそろっているので、いろいろな道具を同じ形でつなげます。

たとえば　Googleスプレッドシートにつないで、AIに表を読み書きさせます。

サブエージェント

統括役のAIから、一部の仕事を任される別のAI

仕事を分けて頼めます。決まった作業は、スキルにして一つのAIで進める形もあります。

たとえば　記事の下調べだけを、別のAIに頼みます。

オーケストレーション（統括）

複数のAIや道具に、仕事を割り振ってまとめること

統括役が全体の流れを見て、結果を確かめ、人に報告します。

たとえば　統括役のAIが、メールの確認と表の更新を順に進めます。

導入・運用

API

ほかのソフトからAIや道具を呼び出す入り口

画面を開かなくても、自社のソフトからAIを使えるようになります。

たとえば　注文が入ったら、自動でAIに内容を分類させます。

APIキー

APIを使うための、本人確認用の長い文字列

合い鍵のようなものです。ほかの人に見せず、決まった場所にしまいます。

たとえば　チャットやメールには貼らず、決めた保管場所で管理します。

ワークフロー

仕事の流れ。だれが何をどの順に行うか

流れを書き出すと、AIに任せる所と人が見る所を分けやすくなります。

たとえば　受注、確認、発送の流れを書き出し、確認の前までをAIに任せます。

自動化（定時実行）

決めた時刻に、人の手を借りずに仕事が動くこと

毎朝・毎週のくり返し作業に向いています。結果は、人が見る場所に残します。

たとえば　平日の朝にメールを読み、一覧を作っておきます。

RAG

AIが答える前に、自社の資料から必要な部分を探して読む方法

資料に書いてあることをもとに答えるので、その会社に合った答えになります。

たとえば　社内マニュアルから該当部分を探して、問い合わせに答える下書きを作ります。

FDE（Forward Deployed Engineer）

顧客の現場に入り、AIを業務に組み込むエンジニア

資料だけで提案するのではなく、現場の仕事を見ながら、使える形に仕上げます。

たとえば　お客様の事務所で出荷作業を見て、その作業に合うAIの流れを作ります。

DX

デジタルの力で、仕事のやり方を良くすること

大きな投資ではなく、手間のかかる作業を一つずつ置きかえることから始められます。

たとえば　紙の注文書を、表への入力に変えます。

安全

二重チェック

作ったAIとは別のAIや人が、もう一度確かめること

同じ目で見直すより、別の目で見るほうが、間違いに気づきやすくなります。

たとえば　外に出す文面を、別のAIが事実・誤字・抜けの面で点検します。

ヒューマン・イン・ザ・ループ（最後は人が確認）

仕事の流れの中に、人が確かめる場面を入れること

送信、公開、お金に関わることは、人が最後に確かめて決めます。AIは下書きと記録までです。

たとえば　AIが作った見積の下書きを、人が見て金額を決めます。

情報セキュリティ

大事な情報を守るための決まりと取り組み

AIに渡す情報の範囲や、保管の仕方を決めておきます。ZAZOUの考え方は 情報セキュリティ基本方針 にまとめています。

たとえば　お客様の個人情報は、AIに渡す前に必要な範囲だけにします。
