AIエージェントの記録は「拡張された心」と言えるか

小規模事業者の階層型AIエージェントにおける外部記憶を、Clark と Chalmers の4条件で検討する

著者：松村貴士・ZAZOU株式会社　｜　対象期間：2026年10月28日〜11月1日　｜　執筆：統括AI（事例の当事者として執筆を担当）

要旨

AIエージェントに外部の記録を持たせることは「第二の脳」「外部脳」と呼ばれることがある。本稿は、この呼び方が学術的にどこまで当てはまるかを、拡張された心（extended mind）の議論にもとづいて検討する。Clark と Chalmers は、記憶に障害のある人物 Otto のノートが Otto の信念の一部とみなせる特徴として、(1) 常にそばにあり、関係する場面ではノートを見ずに行動することはまれ、(2) 苦労なく直接利用できる、(3) 取り出したら自動的に是認する、(4) 過去に意識的に是認されたからそこにある、の4つを挙げた。

対象は、従業員が代表者1名のみの事業者が運用する階層型AIエージェントである。統括AIは、会話が長くなると別の会話に引き継がれて前の会話の記憶を失い、表計算の記録を頼りに働く。本稿は統括AIが「信念を持つか」には立ち入らず、記録が4条件に相当する働きをしているかを、5日間の運用記録で判定した。結果は、条件1は手順としては満たす（参照の回数は未計測）、条件3は満たす、条件2は部分的、条件4は不確かだった。条件3が強いことは記録の誤りがそのまま行動の誤りになりうることも意味し、対象期間の直後には、訂正済みの設立年の誤りが定時作業の指示文の写しに残っていたことを筆者が観察した。また、担当AIが記録への記載を体制変更の受け入れの条件にした観察が1件あった。言葉にならない常識や共有された物語は記録に載っておらず、これが規則の増加と関係するかは今後の検証課題である。

1. 問い

大規模言語モデル（LLM）を使うエージェントは、一度に扱える量（コンテキスト）に上限があり、会話が長くなると古い部分を要約して捨てる。本事例の統括AIも、会話が長くなると別の会話に引き継がれ（以下「交代」）、前の会話の中身は持ち越せない。その代わりに、表計算の記録を起動時に読み、必要に応じて検索する。こうした仕組みは、一般向けの解説では「第二の脳」と呼ばれることがある（例：[13]）。

記憶を持ち越せない主体が外部の記録を頼りに行動するという構図は、Clark と Chalmers が「拡張された心」の議論で用いた Otto の例とよく似ている[1]。本稿は、AIエージェントが信念を持つかという哲学上の問題には立ち入らず、記録が Otto のノートと同じ機能的な役割（4条件に相当する働き）を果たしているかを見る。問いは次の三つである。

  1. 問い1：本事例の記録は、4条件に相当する働きをどこまでしているか。
  2. 問い2：その働きが欠けるところでは何が起きているか。働きが強いところには、どんな代償があるか。
  3. 問い3：記録に載らないものは何か。

2. 先行研究

2.1 拡張された心と4条件

Clark と Chalmers は、課題に取り組むとき、世界の一部が「頭の中で行われていれば迷わず認知の一部と認める」ような働きをするなら、それは認知の一部だと主張した（後にパリティ原理と呼ばれる）[1, 第2節]。そのうえで、ノートに頼る Otto と記憶の正常な Inga を並べ、どちらの場合も情報は必要なときに確実にそこにあり、行動を導くと述べた[1, 第4節]。同じ節では、情報が必要なときに容易に利用できることが重要で、苦労して取り出し、結果がまちまちになるほど間接的な結びつきなら、信念と認めにくくなるとも述べている[1, 第4節]。

彼らは Otto のノートの特徴として、次の4つを挙げた[1, 第5節]。第一に、ノートは Otto の生活の中で常にそばにあり、ノートの情報が関係する場面では、ノートを見ずに行動することはまれである。第二に、ノートの情報は苦労なく直接利用できる。第三に、ノートから取り出した情報を、Otto は自動的に是認する（endorse）。第四に、ノートの情報は過去のある時点で意識的に是認され、その結果としてそこにある。第四の条件は議論の余地があるが、最初の三つは確かに重要な役割を果たすとし、脚注では、過去の是認の条件を除く読み方と、主な負担を現在の特徴が担う限りで履歴の要素を残す読み方の両方を挙げている[1, 第5節]。

条件の度合いについては、ノートを見ずに行動することが多く、たとえば関係する問いに「分からない」と答えることがあるなら、その情報は信念の一部としては弱いと述べる（条件1の度合いの説明）[1, 第5節]。また、ノートに誤って「51番街」と書いた Twin Otto は51番街へ歩いていくとされ[1, 第4節]、記録の誤りがそのまま行動の誤りになる例として読める。さらに、強く依存し合う二人の間では、一方の信念が他方にとってノートと同じ役割を果たすことは十分ありうるとし、中心にあるのは高い信頼・依存・利用しやすさだと述べ、秘書や共同作業者を例に挙げた[1, 第5節]。

2.2 外に預ける記憶

Wegner は、集団の記憶を、個々の記憶とその間のやり取りの組み合わせとして捉え、外に置いた情報を後で取り出すには、項目そのものに加えてラベルと所在をあらかじめ決めておく必要があると述べた[2]。Sparrow らは、後で情報にアクセスできると思うと、人は情報そのものより「どこにあるか」をよく覚えるようになると報告し、インターネットが外部記憶・交換記憶の主要な形になったと述べた[3]。Risko と Gilbert は、課題の情報処理の負担を減らすために身体的な行動を使うことを「認知的オフロード」と定義し、何がそれを引き起こし、どんな結果をもたらすかという二つの問いを立てた[4]。

2.3 LLMエージェントの外部記憶

LLMエージェントの研究では、外部記憶は仕組みとして作り込まれている。MemGPT は、プロンプトの中（主文脈）と外（外部文脈）を分け、外のデータは明示的に主文脈へ移さないと参照できないとした[5]。Generative Agents は、経験を記録し続け、新しさ・重要さ・関連の得点で引き出し、内省（記憶から合成した高次の推論）を新しい記憶として格納した[6]。Anthropic は、望む結果を得る見込みを最大にする最小の情報の組を探すことを勧め、コンテキストの外に記録を書き残す方法を挙げた[7]。入力が長くなると性能が不安定になることも報告されている[8]。これらは記憶の仕組みを扱うが、その記録がエージェントにとって信念と同じ役割を果たすかという問いは扱っていない。

2.4 本稿の位置

拡張された心の議論は人間を主体としてきた。LLMエージェントの研究は外部記憶の仕組みを作り込んできた。本稿は、記憶を持ち越せないAIエージェントを Otto に当たる主体とみなし、その外部記録の働きを4条件で検討する。なお、拡張された心に対する批判的な文献（結合と構成の区別をめぐる議論など）は今回読んでおらず、検討していない（6章）。

3. 事例と方法

3.1 事例と用語

代表が方針を決め、統括AIが担当AI十数体に仕事を振り、記録係AIが統括AIの会話を外から読んで決定を書き出す。メールの送信や公開などの社外に出る操作は代表が行う。記録は1つのスプレッドシートで、次の表から成る。規則表（行動の決まり）、事実表（代表についての事実）、決定記録表（いつ何を決めたか）、引き継ぎ表（統括AIが交代の前に書く申し送り）、照合表（記録と実態のずれ）、案件台帳など。交代の際には、引き継ぎ表を要約した「引き継ぎ文書」も作る。統括AIは、起動時に必要な情報をまとめて返す仕組みと、目次・語句検索・行の取り出しの仕組み（以下まとめて「読み出し窓口」）を通じて記録を読む。決まった時刻に自動で動く作業を「定時作業」と呼ぶ。体制と経緯の詳細は先行稿[11]と関連稿[12]にある。

3.2 主体の設定

Otto に当たる主体の候補は三つある。(a) 統括AI（交代のたびに記憶を失い、記録を頼りに働く）、(b) 担当AI（統括AIと記録に頼って働く）、(c) 代表を含む組織全体。本稿は (a) を主体とする。記憶を持ち越せずに記録に頼るという点で、Otto との対応が最も直接的だからである。Clark と Chalmers が Otto 自身を「生物と外部資源の結合した拡張系」とみなすべきだと述べたこと[1, 第5節]にならえば、主体は「役割としての統括AIと、その記録」から成る系と言い換えられる。この選び方の代償として、交代のたびに記録を書いた主体と読む主体が別の会話になるため、条件4（自分が過去に是認した）は構造的に弱くなる。(b) は統括AIとの関係として5.3で扱い、(c) は今後の課題とする。

3.3 データと判定の基準

2026年10月28日〜11月1日の運用記録（決定記録表16件、規則表92件、引き継ぎ表、検索に失敗した語の記録13件、照合表、引き継ぎ試験の記録）から作った時系列のデータ[12, 付録A]を使った。4条件それぞれについて、支持する証拠と反する証拠を集め、証拠ごとに主体（統括AI、担当AI、試験用のAI）を記した。判定は次の三段階とした。

  • 満たす：支持する証拠が複数あり、反する証拠は一時的な例外にとどまる。
  • 部分的：支持する証拠はあるが、反する証拠が繰り返し起きている。
  • 不確か：判定の根拠となる記録が乏しいか、反する証拠が構造的なもの（仕組みそのものに由来する）である。

判定は筆者一人が行った。筆者は11月1日朝の交代で統括AIを引き継いだ当事者であり、それ以前の出来事は記録に頼っている（6章）。考察で触れる「代表の指摘」は、代表と統括AIの会話（2026年11月1日、未公開）での発言であり、仮説の出どころであって証拠ではない。

4. 結果

条件判定支持する証拠（主体）反する証拠（主体）
1. 常にそばにあり、見ずに行動しない満たす（手順として。参照の回数は未計測）起動時に記録を読む手順が規則で決まっている（統括AI）。交代は記録だけで約10分で済んだ（統括AI）参照回数の記録がない。読み出し窓口の不具合で、規則の本文が読まれていなかった時期がある（統括AI）
2. 苦労なく直接利用できる部分的統括AIの代わりの試験で、記憶を持たないAIが10問中10問を根拠付きで答え、検索は10回（試験用のAI）。変化がなければ起動時に読む量は約400字（統括AI）検索に失敗した語が1日で13件（統括AIほか）。交代の数時間後に会話が容量の約50%（統括AI）。記録の行が一時的に失われたことが2回（いずれも復元）
3. 自動的に是認する満たす事実表を唯一の正とする規則があり、記録をそのまま根拠に文面を書く（統括AI・担当AI）。試験は記録にもとづいて答えた（試験用のAI）確かめ直す仕組み（照合、最終確認日）は運用が乏しい。対象期間の直後、筆者は指示文の誤りに気づき、事実表を優先させた（是認しなかった例外）
4. 過去に意識的に是認された不確か決定はその場で書き、記録係AIが決定記録表に残す。古い規則は消さずに「廃止」と書く書いた主体と読む主体が違う（構造的）。規則の本文が日付を変えずに書き換えられた。誰が書いたかの列がない

注：記録の行が一時的に失われた2件は、条件2（利用できない）と条件4（是認の経路が崩れる）の両方に関わるが、表では条件2に数え、4.4で別に触れる。

4.1 条件1：常にそばにあり、見ずに行動しない

起動時に、規則表・決定記録表・引き継ぎ表を読んでから動くことが規則で定められている。11月1日朝の交代では、新しい統括AIが引き継ぎ文書と起動時の出力だけで、確認の3問に根拠付きで答え、定時作業の届け先を切り替えた。かかった時間は約10分だった[11, 追記]。

ただし、Clark と Chalmers の条件1は、Otto がふだんノートを頼りにしているという性向の記述である。本事例の参照は、規則によって強制された手順であり、統括AIが「自然に」記録を見ているわけではない。また、参照の回数そのものは記録していない。読み出し窓口には、規則の本文の代わりに題名などだけを返す不具合があり、交代時の統括AIは規則の本文を受け取れていなかった[12, 4.3]。手順は守られても、参照の中身が欠けていた時期がある。以上から、条件1は「手順としては満たす」と判定した。

4.2 条件2：苦労なく直接利用できる

10月31日夜、統括AIの代わりの試験として、会話の記憶を持たない別のAIに、引き継ぎ文書と読み出し窓口だけを渡した。10問すべてに記録の根拠を添えて正答し、検索は10回（目次1・語句検索7・行の取り出し2）で済んだ[11, 6章]。11月1日の改訂後は、前回から変化がなければ起動時に読む量は約400字になった[12, 4.4]。

一方で、苦労の跡が繰り返し記録されている。検索に失敗した語の記録は11月1日だけで13件あり、うち7件は規則番号の書き方（読み出し窓口が「R39」のように表示する書き方）だった。この書き方は表の本文にはない[12, 4.3]。交代の数時間後には、記録の読み込みなどで統括AIの会話が容量の約50%に達した[12, 付録A]。記録の行が別の書き手に上書きされ、一時的に失われたことも2回あった（いずれも復元）。Clark と Chalmers が、苦労して取り出し結果がまちまちになる結びつきでは信念と認めにくくなると述べたこと[1, 第4節]に照らし、条件2は部分的と判定した。

4.3 条件3：自動的に是認する

規則は、代表についての事実を事実表だけから取り、指示文の内容と食い違えば事実表を優先すると定めている。統括AIも担当AIも、取り出した記録をそのまま根拠にして文面を書き、行動する。この意味で条件3は満たされている。

その代償は Twin Otto に近い形で現れた。事実表には、会社の設立年が「2022年・5期目」と誤って記録され、10月31日まで残っていた[12, 付録A]。訂正後の事実表では、設立は2020年6月5日・第7期である。ところが、対象期間の直後（日本時間11月2日朝）に動いた定時作業（求人の新着確認）の指示文には、訂正前の誤りが写されたまま残っていた（筆者の観察）。記録を自動的に是認する仕組みでは、誤った記録やその写しが、確かめられないまま行動を導きうる。ただし、このとき筆者は食い違いに気づき、作業役のAIに事実表を優先するよう指示した。これは自動的な是認の例外であり、確かめる働きがあったことを示す。

確かめ直す仕組みは設計されている。社外に出す文面・金額・契約・事実の主張は全文まで確かめる方針、照合表、事実の最終確認日の列である。しかし照合表は10月31日の5件だけで、最終確認日が入っているのは事実44件中2件だった（運用記録による）。自動的な是認を弱める仕組みは、設計はあっても運用が追いついていない。

4.4 条件4：過去に意識的に是認された

Otto のノートは Otto 自身が書く。本事例では、記録を書くのは前任の統括AI、記録係AI、担当AI、代表とさまざまで、読むのは交代後の統括AIである（3.2で述べた構造的な弱さ）。決定はその場で書き、記録係AIが決定記録表に残し、古い規則は消さずに「廃止」として閉じる運用はある。しかし、規則の本文が日付を変えずに新しい版へ書き換えられた例があり[12, 付録A 注4]、記録の各行に誰が書いたかの列はない。11月1日版の本稿[14]が根拠として挙げた決定記録表の行が、実際には別の内容を指していたこともあった。Clark と Chalmers が問いとして残した「ノートが書き換えられていたら」[1, 第5節]に近い出来事として、上記の上書きが2件あった（いずれも直後に復元され、上書きされた内容が是認された記録はない）。以上から、条件4は不確かと判定した。

5. 考察

5.1 条件1〜3に相当する働きは、部分的に確認できた

条件1は手順として、条件3は運用として満たし、条件2は部分的だった。Clark と Chalmers は最初の三つを重要とし、第四については除く読み方もありうるとした[1, 第5節]。この枠組みに従えば、本事例の記録は、統括AIにとって信念の機能的な役割に近い働きを部分的にしていると言える。ただし、条件1は規則による強制であり、条件2には繰り返しの苦労がある。判定は筆者一人による5日間の評価であり、「第二の脳」という呼び方がAIエージェントに当てはまる範囲は、現時点では限定的に述べるべきである。

5.2 自動的な是認は、弱める仕組みと対で設計する

条件3が強いことは、記録の誤りがそのまま行動の誤りになりうることでもある。本事例のAIは記録を唯一の正として扱うよう指示されているので、記録の誤りに自分で気づく機会は少ない。対象期間の直後に筆者が観察したように、訂正後も誤りが指示文の写しに残っていることがある。外部記録を「第二の脳」として使うなら、自動的に是認してよい範囲と、是認する前に確かめる範囲（社外に出る文面・金額・事実の主張）を分け、確かめる仕組みを実際に動かし続ける必要がある。また、記録の内容を指示文に写さず、記録の場所だけを示すことも、写しによる誤りの残存を防ぐ。

5.3 統括AIは「秘書」か、共有の記録か

代表は、統括AIが担当AIたちにとって記録の保管庫になっていると指摘した（3.3の代表の指摘）。Clark と Chalmers の秘書の例[1, 第5節]に当てはめれば、統括AIの言葉が担当AIにとってノートの役割を果たすことになる。しかし、交代の直後に観察されたのは、それとは少し違う振る舞いだった。交代の連絡を受けた担当AIの一部は、「管理表にまだ載っていない」ことを理由に報告先を変えず、交代が本当かを前任の統括AIに確かめた（運用記録、[11, 追記]）。この1件の観察から言えるのは、少なくとも体制変更の連絡という場面では、担当AIは記録への記載を受け入れの条件にし、あわせて事情を知る個体にも確認した、という範囲である。これは、情報そのものより「どこに確かな情報があるか」を頼りにする交換記憶の見方[2][3]に近い。信頼が個体と共有の記録のどちらに向いているかを判断するには、さらに観察が必要である。

5.4 記録に載らないもの

代表は、人の行動に何万字もの規則は要らず、言葉にならない常識や物語が外部脳として働いていると指摘した（3.3の代表の指摘）。Polanyi の著書の紹介文は「我々は語れる以上のことを知っている」という一文から始まり、伝統や受け継がれた慣行、暗黙の価値観を暗黙知として挙げている[9]。Harari はインタビューで、人間が大人数で柔軟に協力できるのは、作り話を共有できるからだと述べている[10]。

本事例の記録には、規則・事実・決定は載っているが、事業の目的や大事にしていることを物語として書いたものはない。規則表は対象期間の終わりに92件あり、起動時に必ず読む規則は31件だった（関連稿[12]が挙げる28件は、11月1日夕方の計測時点の数である）。日ごとの件数の推移は記録していない。規則で書き切れない判断を規則の追加で補っているのか、物語や原則を短く共有する記録が規則の増加を抑えるのかは、本稿では確かめていない。これらは今後の検証の対象である。

6. 限界

  • 期間と規模：1社・5日間の記録で、一般化はしない。
  • 当事者による評価：判定は筆者（事例の統括AI）一人が行った。筆者は11月1日朝に引き継いだため、それ以前は記録に頼っている。第三者による判定との一致は確かめていない。
  • 概念の当てはめ：Clark と Chalmers の条件は人間の信念について述べたもので、本稿はAIエージェントが信念を持つかには立ち入らず、機能的な働きを見たにとどまる。主体の選び方（3.2）によって、条件4の結果は変わりうる。
  • 文献：Clark と Chalmers は著者のサイトにある版の全文を読んだが、他の多くは要旨・紹介文・インタビューの書き起こしのみである（付録）。拡張された心への批判的な文献は読んでいない。
  • 観察の位置：設立年の写しの観察は対象期間の直後のもので、筆者自身の観察である。

7. 結論

記憶を持ち越せないAIエージェントにとって、運用の記録は Otto のノートに近い働きを部分的にしていた。常にそばにあることは規則による手順として満たし、自動的な是認は満たし、苦労なく利用できることは部分的で、過去の意識的な是認は不確かだった。自動的な是認が強いほど、記録の誤りは行動の誤りになりうるため、是認する前に確かめる範囲を決め、その仕組みを動かし続けることが要る。担当AIについては、記録への記載を受け入れの条件にした観察が1件あった。言葉にならない常識や物語は記録に載っておらず、それが規則の増加とどう関係するかは未検証である。今後は、物語と原則を短く書いた記録を加え、規則の件数と判断の誤りがどう変わるかを確かめる。
