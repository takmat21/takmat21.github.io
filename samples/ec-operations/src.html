EC商品の運用：毎日・毎週・毎月のやること

Amazon・Yahoo!ショッピング・BASE で商品を売り続けるための、決まった仕事の一覧

EC運営の仕事は、毎日の「止めない仕事」と、毎週・毎月の「伸ばす仕事」に分かれます。止めない仕事を決まった時刻・決まった順で片づけると、伸ばす仕事に時間が残ります。
毎日（約60分）注文・出荷・問い合わせ・在庫
→ 2ページ
→
毎週（約2時間）売上と広告・レビュー・価格
→ 3ページ
→
毎月（約半日）商品ページ・写真と説明文・季節
→ 4〜5ページ

この資料の使い方

2〜4ページのチェックリストを担当者に渡し、終わったら日付を書いてもらいます。6〜7ページは、対応の型と注意点です。

例について

例に出す「ミナト生活雑貨」・商品・数字は架空です（会社名・数字は変更しています）。時間は商品30点ほどの店の目安です。

毎日のチェックリスト

午前と午後の2回、同じ順で回します。漏れると、出荷遅れ・評価の低下に直結する仕事です。

1注文

  • 3モールの新しい注文を確かめた
  • 保留・キャンセル依頼を見た

2出荷

  • 伝票を作り、期限の近い注文から出した
  • 出荷した注文に追跡番号を入れた

3問い合わせ

  • 3モールの問い合わせ欄を全部開いた
  • その日のうちに一次返事をした（迷う件は担当者へ）

4在庫

  • 台帳の数を3モールに反映した
  • 発注点割れの報告・返品を「検品待ち」へ
時刻（例）やること
10:00注文の確認 → 伝票づくり → 問い合わせの一次返事 → 在庫の反映
15:00午後の注文の確認 → 出荷と追跡番号の入力 → 問い合わせの残り → 発注点の報告
モールごとに出荷期限・返事の目安の決まりがあります。期限は各モールの管理画面・ヘルプで確かめて、チェックリストに書き込んでおきます。

毎週のチェックリスト

週に1回（例：月曜の午前）、数字を先週と比べて、手を打つ商品を3つまでに絞ります。

売上と広告

  • 商品ごとの売上・注文数を先週と比べた
  • 広告費÷広告経由の売上（比率）を見た
  • 売れない検索語を広告から外した

レビュー

  • 新しいレビューを全部読んだ
  • 星1〜2の理由を分類した
  • 返事が要る件に返事した（できるモールのみ）

価格

  • 同じ商品・近い商品の値段を見た
  • 3モールの値段の差を確かめた
  • 送料込みで利益が残るか計算した
週の記録の例（架空）先週今週次の手
保冷ボトル 売上186,000円152,000円検索の順位と在庫切れの日がないかを見る
広告費の比率（広告費÷広告売上）18%27%上位の検索語を見直し、社内の目安（20%）以下へ
星1〜2のレビュー0件2件「ふたが固い」→ 説明文に開け方を足す

毎月のチェックリスト

月に1回、商品ページを1〜3点ずつ直し、2か月先の季節に備えます。

商品ページの改善

  • 売上の上位・落ちた商品を選んだ
  • 5ページの手順で直した
  • 直した日と内容を記録した

写真・説明文

  • レビューの質問を説明文に足した
  • 大きさが分かる写真がある
  • 3モールで内容がそろっている

季節の準備

  • 2か月先の行事を確かめた
  • 仕入れ量と発注点を直した
  • 季節の言葉を商品名・説明に足した
準備する月売る時期やること（例）
3月5〜8月（夏）保冷ボトルの在庫を厚くする。「保冷」「夏」の写真を差し替える
9月11〜12月（年末・贈り物）ギフト包装の案内、贈り物向けの写真と箇条書きを足す
毎月モールの大きなセールセールの日程・参加の条件を各モールの案内で確かめ、在庫と価格を決める

商品ページの改善の手順

一度に全部変えず、1回に1か所。直す前の数字を残し、2〜4週間後に比べます。

① 題名何か・誰向けか・大きさを先頭に
→
② 画像1枚目は商品だけ、2枚目以降で使う場面・大きさ
→
③ 箇条書き1行に1つの利点。数字で書く
→
④ 検索語レビュー・問い合わせの言葉を拾う
場所直す前（架空）直した後（架空）
題名【大人気】おしゃれ ボトル 水筒 便利 おすすめ保冷ボトル 500ml 真空二重 紺 食洗機対応 通勤用
箇条書きとても冷たさが続きます氷を入れた水が6時間後も冷たい（自社の試験）
画像白背景の1枚だけ手に持った写真・かばんに入れた写真・寸法の図
検索語「水筒」だけ「マグボトル」「ステンレスボトル」など、買う人が使う言い方
題名の文字数・使えない記号・画像の決まり（背景の色など）はモールとカテゴリごとに違い、変わることもあります。直す前に各モールの出品ガイドラインで確かめます（数字はここでは書きません：要確認）。

レビューと問い合わせへの対応の型

返事は「お礼 → 事実の確認 → 次にすること」の順。言い訳から始めません。

よくある内容最初の返事（型）社内でやること
届かない追跡番号と今の状況をお伝えし、届く見込みを書く配送会社に確認。住所の誤りなら再送の手配
壊れていた・違うおわびと、写真を送っていただく方法を書く交換か返金を決める。返品は「検品待ち」へ
使い方の質問答えと、説明書・商品ページの該当箇所を書く同じ質問が2回来たら商品ページに足す
星1〜2のレビュー（返事ができるモールのみ）お礼と、改善したことを短く理由を分類し、毎週の記録に入れる

返事の文例（架空・届いた商品が違う場合）

ご連絡ありがとうございます。ご注文と違う色の商品が届いたとのこと、ご迷惑をおかけし申し訳ございません。お手数ですが、届いた商品の写真をこちらに送っていただけますか。確認でき次第、正しい商品を本日中に発送いたします。届いた商品の返送方法は、あわせてご案内いたします。
しないこと：お客様の使い方のせいにする／返事を翌々日以降に延ばす／レビューの書き直しや削除を頼む／個人情報をレビューの返事に書く

モールのルール違反を避ける注意

違反は出品の停止につながります。迷ったら「公式の文書で確かめてから」が決まりです。

やりがちなこと危ない理由確かめる所
割引・返金と引き換えに高い評価を頼むレビューを不正に操作する行為として、規約違反になるおそれ各モールのレビューの規約（要確認）
広告と分からない形で紹介してもらうステルスマーケティングは、2023年10月1日から景品表示法の対象消費者庁の案内
「No.1」「最安」を根拠なしで書く実際より良く・安く見せる表示は景品表示法で問題になりうる消費者庁の案内／モールの出品ガイドライン
購入者に自社サイトや連絡先を案内する購入者への連絡の範囲は、モールごとに決まりがある各モールの規約（要確認）
他社の写真・説明文をそのまま使う著作権の侵害。削除の申し立てを受ける自社で撮る・書く
化粧品・食品などで効き目をうたう薬機法など、商品の種類ごとの法律がある所管する役所の案内

出典（確認日 2026-11-06）：消費者庁「ステルスマーケティングに関する景品表示法の規制」caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing/ 。モール各社の規約は出品者用の管理画面で読むため、この資料では条文を引用していません。

ZAZOUができること（代行の範囲）

毎日の「止めない仕事」から、毎月の「伸ばす仕事」まで、範囲を決めて引き受けます。

範囲内容
毎日の運用注文の確認、出荷の手配と追跡番号の入力、問い合わせの一次返事、在庫の反映
毎週の見直し売上と広告の記録、レビューの分類と返事、価格の確認。週1回、短い報告を出します
商品ページの改善題名・画像の構成・箇条書き・検索語の見直し。直す前後の数字で効果を確かめます
季節の準備2か月先の行事に合わせた仕入れ量の見直し、写真と説明文の差し替え
手順書づくりこのチェックリストを御社の商品・体制に合わせて作り直し、社内の誰でも回せる形にします

御社にお願いすること

モールのアカウントの持ち主としての判断（値下げ・返金の上限、広告費の上限）と、ログインの権限の付与をお願いします。
